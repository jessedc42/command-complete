# v0.2.0

This release adds Ubuntu 24.04 support. The editor detects the operating system at startup and loads the matching offline command catalog.

## Added

- An Ubuntu catalog built from 2,670 executable names and 2,278 installed manuals collected on Ubuntu 24.04.5 LTS. It includes flag metadata for 1,932 commands.
- Portable AWS CLI and kubectl schemas in the Ubuntu catalog. Their completions remain available when those tools are absent from the machine.
- A standard-library Python collector for OS details, PATH executables, and installed manuals.
- An inventory import option in the catalog builder. Ubuntu catalogs can be rebuilt from collected documentation without installing AWS CLI, kubectl, or mandoc on Ubuntu.

## Improved

- GNU manual parsing now handles blank lines before descriptions and aliases with argument placeholders.
- Ubuntu OpenBSD netcat uses its documented flag conflicts and argument hints. For example, it permits `nc -l -p`.
- GNU sed expression examples are available through `--expression` as well as `-e`.
- Raw inventory and manual collections are excluded from Git. The compressed Ubuntu catalog is bundled with the source.

## Compatibility and validation

The editor requires Python 3.10 or newer with curses. Prompt handoff uses the existing Bash 5+ or zsh integration.

The bundled catalogs target macOS and Ubuntu 24.04. Commands without usable manual entries retain name completion. Other Linux distributions and Ubuntu releases need their own catalog support.

All 46 tests passed locally, including checks for platform selection, GNU options, optional CLI availability, and Ubuntu netcat behavior. The interactive utility has yet to be tested on the Ubuntu host.
