# v0.3.0

Adds `command-search` (`cs`), an offline task-keyword search utility sharing
command-complete's catalogs, completion engine, installation, and version.
Uses Python's standard library only; requires Python 3.10+ with curses/SQLite.

- Live case-insensitive word-prefix search with inclusive keywords, distinct-word
  ranking, alphabetical ties, and strict `get` / `set` effect filters.
- Full macOS and Ubuntu catalog indexing, including inherited flags and portable
  AWS CLI, kubectl, and Docker schemas when those tools are absent from the host.
- Frozen search references above live completion, keyboard-selectable flags,
  documented conflict reasons, guided multi-flag values, and retained drafts
  when stepping back through the search.
- Ctrl+X then Ctrl+G opens search from the shell prompt; Ctrl+G continues to open
  cc. Bash 5+ and zsh receive the final editable, unexecuted draft. Standalone
  entry points print the draft. Cancellation restores the original shell input.
- Source-backed command/flag descriptions imported from installed AWS reference
  models and CLI help, macOS manuals, and collected Ubuntu manuals. Descriptions
  also improve cc. Coverage reports preserve remaining gaps and unknown effects.
- Read-only SQLite search snapshots with a per-user first-use cache and catalog
  fingerprint checks; no runtime network access or third-party Python packages.
- Non-overwriting installation of both utilities and `cs`, Unicode-aware shell
  cursor handoff, and corrected AWS output-file positional metadata.

See [README](../README.md) for installation, controls, refresh instructions, and
the [coverage report](../search-coverage.md) for counts and measured timings.
Effect labels describe documented catalog forms, not arbitrary edited drafts.
Final publication requires review of remaining documentation gaps and native
Ubuntu validation. This file prepares release notes; it does not publish a tag
or GitHub release.
