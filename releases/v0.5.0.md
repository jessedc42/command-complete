# v0.5.0

Adds command-name exclusions to command-search and wraps command and flag purpose
descriptions across command-complete and command-search.

## Command-name exclusions

- Use `network !aws` to find network matches while excluding AWS command forms.
  When starting from a shell, single-quote the query: `cs 'network !aws'`.
- Exclusions match case-insensitive literal prefixes of executable and subcommand
  names. Descriptions, purpose keywords, flags, and arguments do not trigger them.
- Multiple exclusions all apply: `!aws !docker` lists remaining command forms
  alphabetically. Excluded keywords do not contribute to ranking.
- Ordinary keywords retain inclusive OR matching and distinct-keyword scoring.
  Positive `get`/`set` effect filters retain their behavior; `!get` excludes names
  beginning with `get`, rather than negating the effect filter.
- A lone `!` is ignored while typing. The optional short-query guard retains its
  existing behavior and remains off by default.

## Wrapped purpose descriptions

- Long descriptions wrap in search results, the frozen reference, and live
  completion, retaining distinct command/flag and description colors.
- Resizing reflows the text; narrow views show fewer entries and very narrow
  lists place descriptions below command names.
- Page Up/Page Down scroll through a selected entry taller than its pane before
  jumping to other entries. Arrows continue selecting entries.
- Layout reads only entries near the viewport, preserving lazy result loading.

Runtime remains Python 3.10+ using only the standard library. Existing catalog
and SQLite snapshots work without rebuilding. Hotkeys and editable, unexecuted
draft handoff retain their behavior.

Validation: 172 tests pass on macOS, including real-terminal wrapping, resizing,
scrolling, live exclusions, CLI queries, and installed entry-point version checks.
Native Ubuntu execution was not performed for this release preparation.
